# ParadigmCraft project instructions

At the start of every ParadigmCraft task, read `goals.md` and `memory/PROJECT_MEMORY.md`; use them to resume from the current next actions.

After meaningful research, decisions, or code changes, update `memory/PROJECT_MEMORY.md` with findings and completed work, and update `goals.md` when milestone status changes. Keep notes concise and distinguish verified facts from assumptions.

## Clean-room and data boundaries

- The goal is a Rust reimplementation targeting parity with the installed Visual Paradigm 18.1, not a claim that full parity is already achievable.
- Use independent code and original UI/assets. Do not copy proprietary source, artwork, templates, or other packaged content into this workspace, and do not bypass licensing or access controls.
- Treat local coursework `.vpp`/`.vpd` files as read-only and do not inspect their contents or copy them into this workspace without explicit user approval. Metadata-only inventory is allowed.
- Do not read or expose license files, credentials, or volatile application caches.

## Evidence and implementation

- Record observed behavior separately from hypotheses; cite the app version and evidence source in research notes.
- Prefer public documentation and observable workflows. Keep reverse-engineering analysis local; do not upload proprietary binaries or user projects.
- Keep implementation incremental and test each behavior against a reproducible baseline.
