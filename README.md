# ParadigmCraft

A clean-room Rust reimplementation project targeting functional parity with the locally installed Visual Paradigm 18.1 baseline.

This repository is independent work: no Visual Paradigm source, bundled assets, or coursework project contents belong here. The app remains installed separately and is used only as a reference. See [goals](goals.md), [project instructions](AGENTS.md), and the [inventory notes](inventory/README.md).

**Status:** workspace and metadata inventory are set up; the Rust toolchain and application code are not yet set up.
